# Моё Радио — PWA

Мобильное веб-приложение интернет-радио без серверной части.

## Возможности
- каталог Radio Browser API;
- поиск станций;
- категории: популярное, Россия, Германия, рок, электроника, джаз, chillout, новости;
- крупные карточки популярных российских станций;
- избранное;
- история прослушивания;
- добавление собственных потоков;
- таймер сна;
- эквалайзер с пресетами для CORS-совместимых потоков;
- Media Session (экран блокировки/гарнитура — когда браузер поддерживает);
- PWA и добавление на главный экран iPhone/Android;
- офлайн-кэш оболочки приложения (само радио требует интернет).

## Запуск локально
Не открывайте `index.html` напрямую через `file://`: для PWA и части сетевых функций нужен HTTP(S).

Пример:
```bash
python3 -m http.server 8080
```
После этого откройте `http://localhost:8080`.

## Установка на iPhone
1. Опубликуйте папку на HTTPS-хостинге.
2. Откройте адрес в Safari.
3. Нажмите «Поделиться» → «На экран Домой».

## Важно про эквалайзер
Браузерный Web Audio может обрабатывать только потоки, которые разрешают CORS. Если конкретная станция этого не разрешает, приложение автоматически продолжит обычное воспроизведение без EQ.
